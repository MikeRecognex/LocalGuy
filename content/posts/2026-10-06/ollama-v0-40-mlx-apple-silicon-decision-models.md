Ollama v0.40.0 marks a significant milestone for local LLM deployment on Apple Silicon. The release introduces MLX as the default runtime for supported model architectures, eliminating manual configuration and automatically optimizing inference performance on Mac hardware. This change reduces friction for practitioners who previously had to manually switch runtimes.

Beyond runtime improvements, the release adds support for decision models—a new category of smaller models optimized for specific decision-making tasks—including Cloudflare's Clef model. New model additions include Gemma4, Qwen3.6, and Qwen3.5 variants. For practitioners building local AI applications on Apple Silicon, this release provides both performance gains through MLX integration and access to emerging model types that enable more efficient, task-specific inference.
