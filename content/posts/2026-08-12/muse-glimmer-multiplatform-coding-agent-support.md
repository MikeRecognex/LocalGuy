Muse Glimmer, Meta's latest open-source model, has achieved full multiplatform availability in Ollama, bringing powerful coding agent capabilities to local inference workflows. The model is specifically engineered to power coding agents like Claude Code and Codex, as well as long-running personal assistants, making it a transformative option for developers building AI-augmented development tools that run entirely on-device.

The rollout includes platform-specific optimizations starting with Apple Silicon via Ollama's MLX engine, which delivers state-of-the-art performance on Apple hardware, with NVIDIA and AMD support being added in parallel. This coordinated multi-platform release demonstrates how modern local LLM infrastructure can now support frontier-grade capabilities—tool calling, complex reasoning, and code generation—across diverse hardware targets without sacrificing performance or requiring cloud services.
