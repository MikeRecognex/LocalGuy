As AI agents become more sophisticated and local LLM deployments increase, security considerations grow critical. This new Egress WAF tool built on mitmproxy provides security controls specifically designed to limit AI agents and protect against supply chain attacks like NPM malware.

For practitioners running local LLMs in production or developing agent-based systems, this tool addresses a gap in the deployment landscape by providing network-level security controls. The mitmproxy foundation makes it flexible and extensible, allowing operators to define policies for outbound connections from their AI applications.

[Explore the project on GitHub](https://github.com/esamattis/mitmwall) to understand how it can enhance the security posture of local LLM deployments and prevent unauthorized data exfiltration from AI agents.
