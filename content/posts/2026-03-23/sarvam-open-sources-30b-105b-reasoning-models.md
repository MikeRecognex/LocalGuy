Sarvam AI has open-sourced two new reasoning models—a 30B parameter version and a 105B parameter version—providing developers with powerful alternatives for local deployment. These models are particularly significant for practitioners looking to run reasoning-heavy workloads without relying on commercial API services.

The availability of open-source reasoning models at multiple scales addresses a key gap in the local LLM ecosystem. The 30B model targets resource-constrained environments and edge devices, while the 105B variant serves those with more computational headroom. Both releases democratize access to reasoning capabilities that were previously locked behind paid APIs, allowing organizations to maintain data privacy and reduce inference costs through on-device deployment.

For local LLM practitioners, these models represent an important step toward self-sufficient AI infrastructure. The open-source nature means the community can optimize, quantize, and adapt these models for specific hardware configurations using tools like llama.cpp, GGUF quantization, or other local inference frameworks.
