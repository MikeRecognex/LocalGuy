Tanji Systems has released Ingrid, a local-first note-taking application with a hierarchical grid structure designed for offline use and personal data ownership. The tool emphasizes keeping all data on-device while providing powerful organizational and query capabilities similar to Treesheets.

For practitioners interested in local LLM applications, Ingrid represents the kind of foundation that local AI tools are built upon: systems that work entirely offline without cloud dependencies. This type of infrastructure is ideal for integrating local language models as semantic search, note augmentation, or knowledge base querying layers—all while maintaining complete data privacy and control.

The local-first approach aligns perfectly with edge LLM deployments, enabling the creation of AI-augmented productivity tools that never send data to remote servers. [Explore Ingrid](https://tanji.systems/ingrid/) to see how local-first infrastructure patterns support the next generation of private AI applications.
