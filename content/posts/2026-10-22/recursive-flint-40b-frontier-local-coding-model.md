Recursive has released Flint 40B, a specialized large language model designed for local code understanding and generation tasks. With a 262K-token context window, the model enables processing entire codebases within a single inference session—critical for comprehensive code analysis and multi-step refactoring. Performance benchmarks show 125 tokens per second on Apple Silicon MacBooks, making it genuinely practical for interactive development workflows on consumer hardware.

Flint is optimized for agentic code tasks including repository understanding, bug tracing, feature implementation, and test generation. The model is integrated into Ollama starting from version 0.40.8, bringing it immediately into the local inference ecosystem. For developers building AI-assisted coding tools or deploying code analysis on-device, Flint represents a significant step forward—combining sufficient model capacity for complex reasoning with practical inference speeds that enable real-time use cases without cloud dependencies.
