Perplexity has launched a fully local computer agent for macOS, marking a significant shift toward completely on-device agentic AI. This implementation runs entirely on user hardware without cloud communication, providing both privacy guarantees and latency benefits compared to remote agent architectures. The capability enables local automation and task execution across the Mac ecosystem while maintaining full data sovereignty.

The local-first approach addresses key concerns around privacy and reliability for agents interacting with user systems. By removing cloud dependencies, the system can operate in offline scenarios and provides deterministic behavior without network latency. For practitioners building automation tools or exploring local agentic systems, this release demonstrates the feasibility of sophisticated agent reasoning operating entirely on-device, particularly on Apple Silicon which has emerged as a compelling platform for local inference workloads.
