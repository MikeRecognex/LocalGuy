Running multiple AI workloads simultaneously on edge devices requires careful resource management. This deployment guide shows how to run both Frigate (for video surveillance and object detection) and Ollama (for local LLM inference) on a Minisforum MS-A2 compact server, demonstrating practical strategies for balancing GPU memory, CPU allocation, and thermal constraints.

The guide covers containerization with Docker, memory optimization techniques, and runtime configuration to maximize throughput while maintaining system stability. For practitioners building smart home systems, autonomous agents, or edge AI applications, this architecture provides a proven blueprint for combining vision and language models on modest hardware without cloud dependencies.

[Read the full deployment guide](https://fathomjournal.com/deploying-frigate-ollama-minisforum) for step-by-step instructions, configuration files, and lessons learned from production operation.
