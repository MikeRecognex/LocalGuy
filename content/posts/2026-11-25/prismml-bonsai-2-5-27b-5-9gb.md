PrismML has released Bonsai 2.5, demonstrating that highly capable 27B-class models can run efficiently on consumer hardware. The model fits within just 5.9GB while improving performance on coding tasks and tool use compared to its predecessor—critical capabilities for agentic local AI workloads. This achievement shows that aggressive quantisation techniques can maintain functional parity with larger, uncompressed models.

The compression milestone is significant for practitioners wanting to deploy advanced reasoning capabilities on devices with constrained resources, from laptops to edge servers. With coding and tool-use performance improvements at this footprint, Bonsai 2.5 targets the sweet spot between model capability and practical deployability, making it attractive for applications like local code assistants and autonomous agents that previously required cloud infrastructure.
